# 🩸 BloodLink

> Your blood type. Always with you.

BloodLink connects patients, donors and hospitals in real time. Register your blood type, get a personal emergency QR code, find compatible donors and access real hospital data across Italy and the world.

## Features

- 🪪 **Medical Profile** — Blood type, emergency contacts, personal QR code
- 📲 **Emergency QR Code** — Rescuers scan it for instant vital data
- 💉 **Donor Network** — Find compatible donors nearby
- 🏥 **Italian Hospitals** — 110+ hospitals across all 20 regions with real addresses
- 🆘 **Medical SOS** — Send your location and profile in one tap
- 🌍 **5 Languages** — EN, IT, ES, FR, DE
- 🌗 **Dark / Light mode**

## Emergency Numbers (Italy)
- 🚑 **118** — Ambulanza
- 👮 **112** — Emergenza generale
- 🔥 **115** — Pompieri

## 🚀 Deploy on Vercel (5 minutes)

### Step 1 — Upload to GitHub
1. Go to [github.com](https://github.com) → sign up or log in
2. Click **"New repository"** → name it `bloodlink` → click **Create**
3. Upload all these files (drag & drop or use GitHub Desktop)

### Step 2 — Deploy on Vercel
1. Go to [vercel.com](https://vercel.com) → sign up with GitHub
2. Click **"Add New Project"**
3. Select your `bloodlink` repository
4. Vercel auto-detects Vite/React — click **Deploy**
5. In ~1 minute your app is live at `bloodlink.vercel.app` 🎉

### Local development
```bash
npm install
npm run dev
```

### Build for production
```bash
npm run build
```

## Tech Stack
- **React 18** + **Vite**

- Zero backend (prototype — data is local)
